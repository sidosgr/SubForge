はじめに

セットアップ EXE を実行します。アプリ、メディアツール、オフラインヘルプを含み、必要に応じて WebView2 を準備し、ショートカットと Explorer 項目を追加します。Whisper モデルは設定から別途取得します。初期画面は英語、字幕はギリシャ語、同時処理は 1 ファイルです。ローカルまたはオンライン文字起こしを選び、別言語が必要なら翻訳を設定します。

動画と既存字幕

動画またはフォルダーを右クリックし Create subtitles with SubForge を選びます。Windows 11 ではその他のオプションを表示を開きます。複数選択は同じキューに入り、ドラッグも使えます。サブフォルダーが必要なら再帰検索を有効にします。動画の隣や Subs/Subtitles の一致する SRT、WebVTT、ASS、SSA を先に確認し、その後に埋め込みテキスト字幕を確認します。強制字幕だけのトラックや無関係な字幕は除外します。画像字幕は音声ルートを使います。詳細設定で特定字幕や追加フォルダーを指定できます。

ローカル Whisper

Base または Small を選んでダウンロードし、整合性検証を待ちます。Base は約 141 MiB、Small は 465 MiB です。新しい CPU と 8 GB RAM が出発点で、16 GB なら余裕があります。Python や専用 GPU は不要です。取得後はオフラインで動きます。未使用モデルだけ削除してください。元の言語を指定すれば一貫性が上がり、目標と同じ場合は翻訳を省けます。オンライン代替は明示的に許可します。

オンライン文字起こし

サービスを有効にし自分の API キーとモデルを保存します。Groq は audio/transcriptions を使います。Cloudflare にはアカウント ID と @cf/openai/whisper-large-v3-turbo などが必要です。Gemini は Gemini キーと音声モデルを使います。Deepgram と Speechmatics の初回クレジットは使用を許可し、サービス側の自動課金を無効にします。Speechmatics は対応する元言語の指定が必要な場合があります。独自サービスは multipart と時間情報が必要です。長い音声は分割後に絶対時刻を復元します。

翻訳と CLI

SubForge がこのエージェントを自動で設定し、保存済み設定でバックグラウンド実行します。 ブラウザーで Google ログインを完了してください。ログイン選択が待機している場合は続行を押し、その後完了を押してください。 新しいキーを入力すると保存済みキーを置き換えます。削除ボタンでキーを消去できます。 先にモデルを選んでください。モデルを更新すると利用可能な候補が表示されます。 モデルまたはサービスが見つかりません。モデルを更新し、URL を確認してください。 Cloudflare Workers AI のみで必要です。Cloudflare ダッシュボードに表示されます。 OpenCode Zen は管理された OpenCode CLI で翻訳、接続テスト、モデル更新を実行します。保存済みキーとモデルの順序は維持されます。モデル ID または opencode/<model-id> を入力してください。Zen API の直接呼び出しには切り替わりません。 Google の Antigravity CLI 規約とプライバシーポリシーを確認してください。操作データの共有は無効です。続行を押して同意し、設定を完了してください。 ブラウザーで Google ログインを完了してください。必要ならログインページを開くを押してください。 ログイン補助を閉じました。接続テストでアクセスを確認してください。 Antigravity CLI に保存済み Google セッションがあるため、ブラウザーは不要です。完了後に接続をテストしてください。アカウントの切り替えは、この PC の CLI アカウントをログアウトしてから新しいログインを開始します。 翻訳のまとまりは字幕数と文章の長さで自動制限されます。CLI の空・無効・不完全な応答は小さいまとまりで再試行し、不足する字幕を捏造しません。 OpenAI (ChatGPT): ChatGPT で続ける. 対象の ChatGPT プランで字幕を翻訳します。利用量とアカウントの制限が適用されます。別のアカウントやワークスペースには OpenAI プロバイダーを追加してください。 利用状況を管理.

優先順と費用

矢印でサービスを並べ替え、モデル順も適用されます。再試行、間隔、タイムアウトを設定します。一時的な失敗には増加する待ち時間、上限にはファイル共通の待機を使います。無料枠、初回クレジット、有料、不明は別の分類です。許可しなければ有料と不明の経路を遮断します。アプリは外部口座の請求上限を保証できないので、サービス設定を確認してください。

キューと出力

開始前に目標言語を確認します。一時停止は安全な境界で行い、現在のリクエストは完了する場合があります。再開と再試行は保存した区間を再利用します。キャンセルしても元動画は保護されます。並列数を増やすと資源と無料枠を多く使います。吹替や解説には音声インデックスを指定します。初期出力は動画の隣の UTF-8 SRT、例は Movie.el.srt です。WebVTT、別フォルダー、{name} と {language} の命名、元文保存も使えます。上書きを許可しなければ既存ファイルを残します。

プライバシーと解決方法

オンライン音声には音声、翻訳には文章を送ります。ローカル音声は PC に残りますが、オンライン翻訳は文章を送れます。キーは Windows 保護の保存先にあり設定書き出しには含みません。モデルやキー不足、認証失敗、無音、上限到達は回復可能なエラーです。接続確認は品質の証明ではないので共有前に言葉と時刻を確認してください。キーなしで設定を読み書きできます。アンインストールはアプリとメニューを削除し、モデルと設定は別途削除まで残ります。キャッシュ保存日数は 0 なら保持です。 カードには音声区間、翻訳バッチ、字幕数、モデル、試行回数、待機と経過時間を表示します。マイクは文字起こし、ロゼッタストーンは翻訳を示します。ファイルログで履歴を確認し、ログを書き出すで保存できます。ローカルのファイル名とパスを含みますが、API キー、音声、会話、未加工の端末出力は含みません。共有前に名前を確認してください。キューを消去してもログはアプリデータの logs フォルダーに残ります。再試行は古いエラーを消し、現在の保存設定を使い、有効な保存データを再利用して無効なデータを再作成します。長さゼロの Whisper 字幕にはテキストを失わず短い時間区間を与え、その他の無効な時刻はエラーとして扱います。 Whisper 字幕が音声区間内で始まり区間外で終わる場合、終了を実際の音声長に制限します。テキストと開始は保持します。完全に音声外の字幕はエラーのままです。ログに元の終了、修正後の終了、音声境界と最後の段階を記録します。 アンインストールでデータ削除を選ぶとSubForgeのキー、モデル、設定を削除します。選択しなければ設定を保持し、動画と生成した字幕は削除しません。

アプリの更新

更新を確認. 更新は GitHub の sidosgr/SubForge から取得し、GitHub の SHA-256 で検証します。インストール時はアプリを終了し、設定を保持します。 このリリースには検証可能な Windows インストーラーがありません。

ファイルごとの並列翻訳区間数

同じファイルの1～4区間を同時に翻訳します。個別に保存し、元の順序で結合します。 正常なリクエストには定期的な待機はありません。レート制限時は他の有効なプロバイダーを即座に試し、短い適応的な待機を使います。サーバー指定の再試行時間を守ります。 開いている間、このログは自動更新されます。
