Getting started

Install SubForge using the setup EXE. The installer adds the application and media tools, provisions WebView2 when needed, and creates shortcuts and a File Explorer entry. Whisper models are optional downloads in Settings. Open Settings before the first job: the interface starts in English, the subtitle target is Greek, and one file runs at a time. Choose local or online transcription and configure translation only if a different output language is needed.

Videos, folders and subtitles

Right-click a video or folder and choose Create subtitles with SubForge. On Windows 11 the classic entry is under Show more options. Multiple selections join the same queue. Inside the app, add videos, select a folder, or drag files into the window. Enable recursive scanning to include subfolders. SubForge checks matching SRT, WebVTT, ASS and SSA files beside the video and in Subs/Subtitles folders, then checks embedded text tracks. Forced-only or unrelated tracks are rejected. Image subtitles and burned-in captions use the audio route. Use Advanced settings to select a specific subtitle file or extra folder when matching is ambiguous.

Local Base or Small transcription

Choose Local Whisper and either Base or Small. Press Download and wait for checksum verification. Base is about 141 MiB; Small about 465 MiB. A modern CPU and 8 GB RAM are a practical starting point; 16 GB gives more headroom. CPU processing is supported without Python or a GPU. After download, transcription works offline. Remove a model when no job is using it. Auto-detection is available; set the source language explicitly to improve consistency or skip translation for matching source/target languages. Cloud fallback is off unless you enable it.

Online speech connections

Enable and edit a speech provider, save its API key, then select a supported model. Groq uses an OpenAI-compatible transcription endpoint. Cloudflare also needs an account ID and a model such as @cf/openai/whisper-large-v3-turbo. Gemini uses a Gemini API key and an audio-capable model. Deepgram and Speechmatics offer introductory credits; enable Use introductory credits explicitly and disable automatic paid billing in the provider account. Speechmatics may require a source-language selection supported by the chosen model. Custom speech endpoints must accept multipart audio/transcriptions requests with timestamped output. The app sends manageable audio chunks and restores absolute timing.

Translation and agent setup

SubForge installs this agent automatically and runs it in the background using your saved settings. Complete Google sign-in in your browser. If the sign-in choice is waiting, press Continue. Then press Finish. Enter a new key to replace the saved key. Delete it with the delete button. Choose a model first. Use Refresh models to see available choices. Model or endpoint not found. Refresh models and check the endpoint URL. Required only by Cloudflare Workers AI. Find it in your Cloudflare dashboard. OpenCode Zen uses the managed OpenCode CLI for translations, connection tests and model refresh. Your saved key and model order are preserved. Enter bare model IDs or opencode/<model-id>. There is no direct Zen API fallback. Review Google’s Antigravity CLI terms and privacy policy. Interaction sharing is off. Click Continue to accept and finish setup. Complete Google sign-in in your browser. If needed, click Open sign-in page. Sign-in helper closed. Test connection to verify access. Antigravity CLI has a saved Google session, so no browser is needed. Finish and test connection. Switch Google account signs out the native CLI account on this PC before opening a new login. Translation batches are automatically limited by cue count and text length. Invalid, empty, or incomplete CLI replies are retried in smaller batches without inventing missing subtitles.

Priority, retries and costs

Move providers up or down to choose their priority. Models within a provider are attempted in the listed order. Enable only routes you want to use. Choose retries, request delay and timeout for each route. Transient failures use bounded backoff; rate-limit waits are shared across files. A failed eligible route falls back to the next configured route. Free access, introductory credit, paid access and unknown cost are different classifications. Paid and unknown-cost routes remain blocked unless Allow paid or unknown-cost routes is enabled. External billing cannot be guaranteed by the app; provider account limits still apply.

Queue, timing and output

Start the queue after checking the subtitle target. Pause takes effect at a safe boundary; the active request may finish. Resume restores completed chunks, and Retry reuses available checkpoints. Cancel stops owned work without altering source videos. Increasing parallel files can use more CPU, RAM and provider quota. Select an audio stream index in Advanced settings when the video contains dubbing or commentary. Default output is UTF-8 SRT beside the video, such as Movie.el.srt. WebVTT, another folder, a filename pattern using {name} and {language}, and retaining a source transcript are available. Existing files are preserved unless replacement is enabled.

Privacy, troubleshooting and removal

Online speech services receive extracted audio; online translation services receive subtitle text. Local transcription keeps audio on the computer, but online translation can still send its text. Keys are held in Windows-protected credential storage and excluded from settings exports. Diagnostics do not include secrets. Missing keys/models, invalid credentials, silent audio, unsupported files or unavailable quotas produce a recoverable error. Connection checks and mocked tests do not prove recognition quality. Review real output timing and wording before sharing. Import/export settings without keys. Uninstall removes app-owned components and Explorer registration; user settings and optional models are retained unless removed separately. Cache retention is configurable; zero means keep. Queue cards show audio parts, translation batches, cue counts, active models, attempts, cooldown and elapsed time. The microphone means transcription; the Rosetta Stone means translation. File log opens a detailed history; Export log saves it for troubleshooting. Logs include local filenames and paths, but omit API keys, audio, dialogue and raw terminal output. Review filenames before sharing. Logs remain in the app data logs folder after clearing finished entries. Retry clears the old error and uses current saved settings, reusing valid checkpoints and rebuilding invalid ones. Zero-duration Whisper cues receive a short bounded interval without losing text; other invalid timings remain errors. Whisper cue endings that extend beyond an audio part are clipped to its actual duration when the cue starts inside that part. Text and start times are preserved. Cues entirely outside the audio remain errors. Logs record the original/repaired end, audio limit and last processing stage. The uninstall data-removal checkbox deletes saved SubForge keys, models and settings. Leave it unchecked to keep your profile. Videos and generated subtitles are retained.
