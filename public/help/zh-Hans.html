开始使用

运行安装 EXE。安装包包含应用、媒体工具和离线帮助，按需安装 WebView2，并添加快捷方式与资源管理器菜单。本地 Whisper 模型在设置中另行下载。默认界面为英语，目标字幕为希腊语，每次处理一个文件。先选择本地或在线转写，需要其他语言时再配置翻译服务。

视频与现有字幕

右键单击视频或文件夹，选择 Create subtitles with SubForge。在 Windows 11 中打开“显示更多选项”。多选文件加入同一队列，也可拖入窗口。需要处理子目录时启用递归扫描。先检查视频旁或 Subs/Subtitles 中匹配的 SRT、WebVTT、ASS、SSA，再检查内嵌文本字幕。仅强制字幕和无关文件会被排除。图片字幕走音频转写流程。高级设置可指定字幕文件或额外目录以解决匹配问题。

本地 Whisper

选择 Base 或 Small，点击下载并等待校验。Base 约 141 MiB，Small 约 465 MiB。现代 CPU 与 8 GB 内存可作为起点，16 GB 更宽裕。无需 Python 或独立显卡。模型下载后可离线转写，仅移除未使用的模型。自动语言检测可用，也可指定源语言以提高一致性；源语言与目标相同时可省略翻译。在线备用服务必须明确启用，默认不会上传本地音频。

在线转写

启用服务，保存自己的 API 密钥并选择模型。Groq 使用 audio/transcriptions。Cloudflare 还需账户 ID，例如模型 @cf/openai/whisper-large-v3-turbo。Gemini 需要 Gemini 密钥和支持音频的模型。Deepgram 与 Speechmatics 提供初始额度，请明确启用并在服务账户关闭自动收费。Speechmatics 可能需要指定受支持的源语言。自定义接口须接受 multipart 请求并返回时间戳。长音频分段处理后恢复绝对时间。

翻译与 CLI

SubForge 自动安装此代理，并按已保存的设置在后台运行。 在浏览器中完成 Google 登录。如有登录选项等待确认，请按继续，然后按完成。 输入新密钥以替换已保存的密钥。使用删除按钮移除密钥。 请先选择模型。刷新模型可查看可用选项。 未找到模型或服务。请刷新模型并检查服务地址。 仅 Cloudflare Workers AI 需要。可在 Cloudflare 控制台找到。 OpenCode Zen 通过受管理的 OpenCode CLI 执行翻译、连接测试和模型刷新。已保存的密钥和模型顺序保持不变。可输入模型 ID 或 opencode/<model-id>。不会回退到直接调用 Zen API。 请查看 Google 的 Antigravity CLI 条款和隐私政策。互动数据共享已关闭。点击继续以接受并完成设置。 请在浏览器中完成 Google 登录。必要时点击打开登录页面。 登录助手已关闭。请测试连接以确认访问权限。 Antigravity CLI 已保存 Google 会话，无需打开浏览器。请完成后测试连接。切换账户会先退出此电脑上的 CLI 账户，再开始新登录。 翻译批次会根据字幕数量和文本长度自动限制。CLI 回复为空、无效或不完整时，会使用更小批次重试，不会编造缺失字幕。 OpenAI (ChatGPT): 使用 ChatGPT 继续. 通过符合条件的 ChatGPT 套餐翻译字幕。受使用量和账户限制。如需其他账户或工作区，请添加另一个 OpenAI 提供商。 管理使用量.

顺序与费用

箭头调整服务优先级，各服务内模型也按列表顺序尝试。配置重试次数、请求间隔和超时。临时错误逐步延迟重试，额度等待在并行文件间共享。免费、赠送额度、付费和未知是不同类别。未启用付费选项时，付费及未知费用路线被阻止。应用无法保证外部账户的账单上限，请检查服务账户设置。

队列与输出

开始前检查目标语言。暂停在安全边界生效，当前请求可能先完成。继续及重试复用已有分段。取消不会修改视频。提高并行数量会消耗更多资源和服务额度。配音或评论音轨可在高级设置指定索引。默认在视频旁保存 UTF-8 SRT，例如 Movie.el.srt。也可选 WebVTT、其他目录、包含 {name} 与 {language} 的文件名及保留源文本。不启用替换时保留已有文件。

隐私与排错

在线语音服务收到音频，在线翻译服务收到文本。本地转写把音频留在电脑，但在线翻译仍会发送文本。密钥保存在 Windows 保护的凭据存储中，不包含在设置导出。模型或密钥缺失、认证失败、静音、额度不足会显示可恢复错误。连接检查不证明识别质量，请在分享前检查用词与时间。设置可不含密钥导入导出。卸载删除应用及菜单，模型与设置保留至另行删除。缓存保留天数可设置，零表示永久保留。 任务卡显示音频段、翻译批次、字幕数量、模型、尝试次数、冷却及耗时。麦克风表示转录，罗塞塔石碑表示翻译。文件日志打开详细历史，导出日志可保存排障记录。日志包含本地文件名和路径，不含 API 密钥、音频、对白或原始终端输出。分享前请检查文件名。清除队列后，日志仍保留在应用数据的 logs 文件夹中。重试会清除旧错误并使用当前已保存设置，复用有效检查点并重建无效检查点。Whisper 零时长字幕会获得短小且有界的时间段，不丢失文本；其他无效时间仍报错。 如果 Whisper 字幕在音频段内开始却在段外结束，结束时间会限定为实际音频时长，文本和开始时间不变。完全位于音频之外的字幕仍报错。日志记录原始及修正结束时间、音频边界和最后处理阶段。 卸载时勾选删除数据会删除 SubForge 密钥、模型和设置。不勾选则保留用户配置。视频和生成的字幕不会删除。

应用更新

检查更新. 更新来自 GitHub 的 sidosgr/SubForge，并与 GitHub SHA-256 校验。安装时将关闭应用并保留设置。 此版本没有可验证的 Windows 安装程序。

每个文件的并行翻译段数

可同时翻译同一文件的 1–4 段。各段分别保存，并按原始顺序合并。 成功的请求没有固定暂停。遇到速率限制时立即尝试其他已启用的服务，并使用短暂的自适应等待。遵守服务器指定的重试时间。 此日志在打开时自动更新。
