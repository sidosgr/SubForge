SubForge 사용 안내

시작하기동영상과 기존 자막로컬 Whisper온라인 음성 서비스번역과 CLI우선순위와 비용대기열과 출력개인정보와 문제 해결앱 업데이트파일당 병렬 번역 구간

시작하기

설치 EXE를 실행하세요. 앱, 미디어 도구, 오프라인 도움말을 설치하고 필요하면 WebView2를 준비하며 바로가기와 탐색기 메뉴를 추가합니다. Whisper 모델은 설정에서 따로 다운로드합니다. 기본 화면 언어는 영어, 자막은 그리스어이며 한 번에 한 파일을 처리합니다. 로컬 또는 온라인 받아쓰기를 선택하고 다른 언어가 필요하면 번역을 설정하세요.

동영상과 기존 자막

동영상이나 폴더를 오른쪽 클릭하고 Create subtitles with SubForge를 선택하세요. Windows 11에서는 추가 옵션 표시를 엽니다. 여러 파일은 같은 대기열에 추가되며 끌어 놓기도 가능합니다. 하위 폴더가 필요하면 재귀 검색을 켜세요. 영상 옆이나 Subs/Subtitles의 일치하는 SRT, WebVTT, ASS, SSA를 먼저 확인하고 내장 텍스트 자막을 확인합니다. 강제 자막만 있는 트랙과 무관한 자막은 제외합니다. 이미지 자막은 음성 경로를 사용합니다. 고급 설정에서 특정 자막이나 폴더를 지정할 수 있습니다.

로컬 Whisper

Base 또는 Small을 선택하고 다운로드한 뒤 무결성 검사를 기다리세요. Base는 약 141 MiB, Small은 465 MiB입니다. 최근 CPU와 8 GB 메모리는 시작점이며 16 GB가 더 여유롭습니다. Python이나 전용 GPU는 필요하지 않습니다. 다운로드 후에는 오프라인으로 작동합니다. 사용하지 않는 모델만 제거하세요. 원본 언어를 지정하면 일관성을 높이고 목표와 같을 때 번역을 생략할 수 있습니다. 온라인 대체는 명시적으로 켜야 합니다.

온라인 음성 서비스

서비스를 켜고 자신의 API 키와 모델을 저장하세요. Groq는 audio/transcriptions를 사용합니다. Cloudflare에는 계정 ID와 @cf/openai/whisper-large-v3-turbo 같은 모델이 필요합니다. Gemini는 Gemini 키와 오디오 모델을 사용합니다. Deepgram과 Speechmatics의 초기 크레딧 사용을 허용하고 서비스 계정의 자동 결제를 끄세요. Speechmatics는 지원하는 원본 언어 선택이 필요할 수 있습니다. 사용자 지정 서비스는 multipart와 시간 정보를 지원해야 합니다. 긴 오디오는 나누고 절대 시간을 복원합니다.

번역과 CLI

SubForge가 이 에이전트를 자동 설치하고 저장된 설정으로 백그라운드에서 실행합니다. 브라우저에서 Google 로그인을 완료하세요. 로그인 선택이 기다리면 계속을 누른 뒤 완료를 누르세요. 새 키를 입력하면 저장된 키를 교체합니다. 삭제 버튼으로 키를 제거하세요. 먼저 모델을 선택하세요. 모델 새로 고침에서 가능한 항목을 확인하세요. 모델이나 서비스를 찾지 못했습니다. 모델을 새로 고치고 URL을 확인하세요. Cloudflare Workers AI에만 필요합니다. Cloudflare 대시보드에서 확인하세요. OpenCode Zen은 관리되는 OpenCode CLI를 통해 번역, 연결 테스트 및 모델 새로 고침을 수행합니다. 저장된 키와 모델 순서는 유지됩니다. 모델 ID 또는 opencode/<model-id>를 입력하세요. Zen API 직접 호출로 전환하지 않습니다. Google Antigravity CLI 약관과 개인정보처리방침을 확인하세요. 상호작용 공유는 꺼져 있습니다. 계속을 눌러 동의하고 설정을 마치세요. 브라우저에서 Google 로그인을 완료하세요. 필요하면 로그인 페이지 열기를 누르세요. 로그인 도우미가 닫혔습니다. 연결 테스트로 접근 권한을 확인하세요. Antigravity CLI에 저장된 Google 세션이 있어 브라우저가 필요하지 않습니다. 완료 후 연결을 테스트하세요. 계정 전환은 이 PC의 CLI 계정을 로그아웃한 뒤 새 로그인을 시작합니다. 번역 묶음은 자막 수와 텍스트 길이에 따라 자동 제한됩니다. 비어 있거나 잘못되거나 불완전한 CLI 응답은 더 작은 묶음으로 다시 시도하며 누락 자막을 지어내지 않습니다. OpenAI (ChatGPT): ChatGPT로 계속. 이용 가능한 ChatGPT 요금제로 자막을 번역합니다. 사용량 및 계정 제한이 적용됩니다. 다른 계정이나 작업 공간은 OpenAI 공급자를 추가하세요. 사용량 관리.

우선순위와 비용

화살표로 서비스 순서를 바꾸며 모델 순서도 적용됩니다. 재시도, 간격, 제한 시간을 설정하세요. 일시 오류에는 점진적 대기, 할당량 제한에는 파일 간 공통 대기를 적용합니다. 무료, 초기 크레딧, 유료, 불명 비용은 서로 다릅니다. 명시적으로 허용하지 않으면 유료와 불명 경로를 차단합니다. 앱은 외부 계정의 청구 한도를 보장할 수 없으므로 서비스 설정을 확인하세요.

대기열과 출력

시작 전 목표 언어를 확인하세요. 일시 정지는 안전한 경계에서 적용되며 현재 요청은 완료될 수 있습니다. 계속과 재시도는 저장된 구간을 재사용합니다. 취소해도 원본 영상은 보존됩니다. 병렬 파일이 많으면 자원과 할당량을 더 사용합니다. 더빙이나 해설에는 오디오 인덱스를 지정하세요. 기본 출력은 영상 옆 UTF-8 SRT, 예를 들어 Movie.el.srt입니다. WebVTT, 다른 폴더, {name}과 {language} 이름 규칙, 원본 텍스트 보관도 가능합니다. 덮어쓰기를 켜지 않으면 기존 파일을 보존합니다.

개인정보와 문제 해결

온라인 음성에는 오디오, 온라인 번역에는 텍스트를 보냅니다. 로컬은 오디오를 컴퓨터에 보관하지만 온라인 번역은 텍스트를 보낼 수 있습니다. 키는 Windows 보호 저장소에 있으며 설정 내보내기에 포함되지 않습니다. 모델/키 누락, 인증 오류, 무음, 할당량 부족은 복구 가능한 오류로 표시됩니다. 연결 확인만으로 인식 품질이 검증되지 않으므로 공유 전에 문구와 시간을 점검하세요. 키 없이 설정을 가져오고 내보낼 수 있습니다. 제거는 앱과 메뉴를 삭제하며 설정과 모델은 별도 삭제까지 남습니다. 캐시 보관 일수에서 0은 계속 보관입니다. 카드는 오디오 구간, 번역 묶음, 자막 수, 모델, 시도 횟수, 대기 및 경과 시간을 표시합니다. 마이크는 받아쓰기, 로제타석은 번역을 뜻합니다. 파일 로그에서 기록을 보고 로그 내보내기로 저장하세요. 로컬 파일명과 경로는 포함되지만 API 키, 오디오, 대화 및 원시 터미널 출력은 제외됩니다. 공유 전 파일명을 확인하세요. 큐를 비워도 로그는 앱 데이터의 logs 폴더에 남습니다. 재시도는 이전 오류를 지우고 현재 저장 설정을 사용하여 유효한 저장 지점을 재사용하고 잘못된 지점을 재생성합니다. 길이가 0인 Whisper 자막은 텍스트 손실 없이 짧은 시간 구간을 받으며 다른 잘못된 시간은 오류로 남습니다. Whisper 자막이 오디오 구간 안에서 시작하고 밖에서 끝나면 끝을 실제 구간 길이에 맞춥니다. 텍스트와 시작 시간은 유지됩니다. 완전히 구간 밖인 자막은 오류로 남습니다. 로그에 원래 끝, 수정된 끝, 오디오 경계 및 마지막 단계가 기록됩니다. 제거 시 데이터 삭제를 선택하면 SubForge 키, 모델 및 설정도 삭제됩니다. 선택하지 않으면 프로필을 유지합니다. 영상과 생성된 자막은 유지됩니다.

앱 업데이트

업데이트 확인. 업데이트는 GitHub의 sidosgr/SubForge에서 제공하며 GitHub SHA-256으로 검증합니다. 설치 시 앱이 닫히며 설정은 유지됩니다. 이 버전에는 검증 가능한 Windows 설치 파일이 없습니다.

파일당 병렬 번역 구간

같은 파일의 1–4개 구간을 동시에 번역합니다. 구간별로 저장하고 원래 순서로 합칩니다. 정상 요청에는 예약된 대기가 없습니다. 속도 제한이 발생하면 다른 활성 제공자를 즉시 시도하고 짧은 적응형 대기를 적용합니다. 서버가 지정한 재시도 시간을 준수합니다. 열려 있는 동안 로그가 자동으로 갱신됩니다.
